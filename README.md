# Excel-Sales-Performance-Analysis-Dashboard
Interactive Excel sales performance analysis and dashboard featuring data cleaning, PivotTables, advanced formulas, statistical analysis, forecasting, and VBA automation.

## Overview

This project demonstrates an end-to-end sales performance analysis workflow built entirely in Microsoft Excel. The workbook transforms raw sales and customer data into structured analysis, statistical insights, forecasting outputs, and an interactive sales dashboard. The project focuses on practical business analytics and demonstrates how Excel can be used for data preparation, analysis, visualization, forecasting, and automation.

---

## Business Objective
The objective of this project is to analyze sales and customer performance and provide actionable insights for business decision-making.

The analysis focuses on:

- Sales and profit performance
- Product category performance
- Country and regional trends
- Customer value segmentation
- Sales channel performance
- Customer purchase behavior
- Discount and revenue analysis
- Statistical analysis
- Sales forecasting
- Dashboard reporting
- Excel-based automation

### 4. Customer Segmentation
Customers are classified based on their sales performance.
The analysis identifies:

- Standard-value customers

- Customer demographics
- Category preferences
---

### 5. Discount & Revenue Analysis
A tiered discount structure is implemented using lookup logic.
Discount tiers include:
| Total Sales | Discount |
|-------------|----------|
| $0–$99 | 0% |
| $100–$499 | 5% |
| $500–$999 | 10% |
| $1,000+ | 15% |

The analysis then calculates:
- Applicable discount
- Discount value
- Adjusted revenue
- ROI
